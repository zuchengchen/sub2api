## 三个可用网址

| 可用网址 | 填到软件里的服务地址 | 说明 |
| --- | --- | --- |
| `mofa.love.gd` | `https://mofa.love.gd/v1` | 稳定入口之一 |
| `mofayaoshipu.cc.cd` | `https://mofayaoshipu.cc.cd/v1` | 稳定入口之一 |
| `key66.cc.cd` | `https://key66.cc.cd/v1` | 稳定入口之一 |

“服务地址”也常被软件写成 `Base URL` 或 `base_url`。它们说的是同一件事：软件要连接哪个网址。

- 三个网址共用同一个账户、余额和 API Key。
- 哪个网址在你的网络下更快、更稳定，就使用哪个。
- 更换网址时，只改服务地址，不需要重新创建 API Key。
- 从任意网址打开 `/guide`，都会留在当前网址，不会跳到另一个域名。
