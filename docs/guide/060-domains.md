“服务地址”也常被软件写成 `Base URL` 或 `base_url`，表示软件要连接的 API 入口。其他客户端按“使用密钥”对应页签填写；例如 Claude Code 的模板使用根地址，不能机械套用本表的 `/v1`。

- 这五个入口在 2026-10-31 核对时均能返回本站健康状态和相同的教程内容；不同网络下的可达性和延迟可能不同。
- 五个入口共用同一套用户、余额、API Key 和使用记录；浏览器登录状态按域名分别保存，换网址可能需要重新登录。
- 更换 API 入口时通常可以继续使用原 Key；修改客户端实际生效的服务地址，并检查是否还有单独配置的模型目录地址。
- 从任意入口打开 `/guide`，教程里的站内链接会留在当前域名。
- 能打开网页或健康检查成功，不代表某个模型一定可用，也不保证生成速度。
