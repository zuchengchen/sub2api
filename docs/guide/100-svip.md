## SVIP 能得到什么、需要注意什么

### 怎样成为 SVIP

- 总余额必须**大于等于 100 元**，系统才会自动升级。
- 余额正好是 100 元时也会升级。例如 99.99 元不可以，100 元可以。
- 升级成功后会一直保留 SVIP，目前不会因为余额降低而自动取消。
- 成为 SVIP **不扣押金**。总余额都可以用于平时调用。

### SVIP 可以得到什么

| 权利 | 通俗说明 |
| --- | --- |
| 计费规则 | 普通用户与 SVIP 使用相同的计费倍率规则，不再因 SVIP 身份额外减免；管理员单独配置的用户倍率仍然有效 |
| Luna 保底 | 所有用户都可以使用 `gpt-5.6-luna`、`gpt-6-luna` 及同系列。当前倍率低于 0.2 时，普通用户与 SVIP 都按 0.2 计费；达到或超过 0.2 时使用原倍率 |
| 有效时间 | 达到条件并升级后长期有效 |
| 站内服务 | 可以使用页面中标明的 SVIP 功能 |

“倍率”是系统计算费用时使用的数字。不同模型和分组的费用仍可能不同，请以实际使用记录为准。

SVIP 不代表所有模型永远都能使用，也不保证每次请求都成功。模型提供方维护、可用余额和本站维护都可能造成暂时不可用。

### SVIP 用户需要遵守什么

- 保护好密码和 API Key，不共享、不出租、不转卖。
- 不使用本站进行攻击、欺诈、滥用或违法活动。
- 遵守站点规则和当地法律。
- 自己承担本站产生的请求和费用。
- 注意可用余额，余额不够时先充值再使用。

违反规则时，站点可能限制模型、API Key、用户或其他服务。
