## SVIP 能得到什么、需要注意什么

### 怎样成为 SVIP

- 本站总余额（含赠送）达到 **100** 时会自动升级，页面单位为美元，显示为 `$100.00`。99.99 未达到条件，100 已达到。
- 这里判断的是**站内余额数值**，不是累计充值额，也不是向外部商店支付人民币 100 元。
- 升级后目前不会因为余额降低而自动取消；管理员仍可按站点规则调整身份。
- 成为 SVIP **不扣押金**，不会因为该身份额外冻结余额。

### SVIP 与计费

**普通用户与 SVIP 使用相同的计费倍率规则**，没有因身份自动减去 0.05 的优惠。管理员单独配置的用户倍率仍然有效，因此不同用户、不同分组的实际倍率仍可能不同。

对于按模型倍率计费的请求：

1. 先使用管理员配置的用户专属分组倍率；没有专属值时使用分组默认倍率。
2. `gpt-5.6-luna`、`gpt-6-luna` 及同系列的这个基础倍率低于 0.2 时，普通用户与 SVIP 都先按 0.2 计费；基础倍率达到或超过 0.2 时保持原值。
3. 使用已配置高峰时段因子的订阅分组时，再按请求时间乘以该因子。因此 **0.2 是 Luna 的基础倍率保底，不是任何情况下的最终倍率**。独立图片、视频价格按对应规则计算。

例如，基础倍率为 0.1、未叠加高峰因子时，普通模型两类用户均使用 0.1，Luna 两类用户均使用 0.2。这个例子不是生产分组的固定报价。

所有用户都可以使用所在分组允许的 Luna 模型，不再要求 SVIP 身份；是否能调用仍受分组、Key 状态、余额或订阅和上游可用性影响。SVIP 不代表所有模型永久可用，也不保证请求成功或另有未在页面说明的功能。

### SVIP 用户需要遵守什么

- 保护密码和 API Key，不共享、不出租、不转卖。
- 不进行攻击、欺诈、滥用或违法活动。
- 遵守站点规则，留意余额、限额和实际费用。
- 出现异常请求时及时停用相关 Key，并联系管理员。

违反规则时，站点可能限制模型、API Key、用户或其他服务。
