## SVIP 能得到什么、需要注意什么

### 怎样成为 SVIP

- 账户总余额必须**严格大于 100 元**，系统才会自动升级。
- 余额正好是 100 元时不会升级。例如 100 元不可以，100.01 元可以。
- 升级成功后会一直保留 SVIP，目前不会因为余额降低而自动取消。
- 成为 SVIP 后，系统会冻结 100 元作为保留金额。这 100 元仍显示在总余额中，但不能用于平时调用。

举例：总余额是 150 元时，可用余额约为 50 元；总余额是 100.01 元时，可用余额约为 0.01 元。

### SVIP 可以得到什么

| 权利 | 通俗说明 |
| --- | --- |
| 专属模型 | 可以使用 `gpt-5.6-luna` 及它的同系列版本 |
| 分组优惠 | 使用 `gpt-pro` 分组时，计费倍率减 0.05，最低不会小于 0 |
| 有效时间 | 达到条件并升级后长期有效 |
| 站内服务 | 可以使用页面中标明的 SVIP 功能 |

“倍率”是系统计算费用时使用的数字。不同模型和分组的费用仍可能不同，请以实际使用记录为准。

SVIP 不代表所有模型永远都能使用，也不保证每次请求都成功。模型提供方维护、账户可用余额和本站维护都可能造成暂时不可用。

### SVIP 用户需要遵守什么

- 保护好账户、密码和 API Key，不共享、不出租、不转卖。
- 不使用本站进行攻击、欺诈、滥用或违法活动。
- 遵守站点规则和当地法律。
- 自己承担本账户产生的请求和费用。
- 注意可用余额。被冻结的 100 元不能用于日常使用。

违反规则时，站点可能限制模型、API Key、账户或其他服务。
