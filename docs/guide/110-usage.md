## 查看余额和使用记录

- **查看余额**：登录后在控制台查看。请重点看“可用余额”，它才是当前能花的金额。
- **查看某个 API Key**：打开[API Key 用量查询](/key-usage)，输入自己的 Key 查看。
- **查看账户记录**：打开[用量记录](/usage)，可以按日期、模型和 API Key 查询次数和费用。
- **查看可用模型**：打开[模型广场](/model-plaza)，查看当前模型、分组和价格说明。

页面里的 `Token` 是模型处理文字时使用的计量单位。新手不需要自己计算，直接查看最终费用即可。

第一次配置、换网址或运行测速工具后，建议先发送一个很小的请求，然后马上查看用量记录。这样可以尽早发现地址或模型填错。
