## 充值：先买兑换码，再兑换余额

当前本站使用**外部商店购买兑换码，再回本站兑换余额**的流程。买完兑换码不等于站内余额已经增加，必须完成兑换。

### 第一步：购买兑换码

1. 登录本站，打开[购买兑换码](/redeem-store)。
2. 页面会展示外部商店；如果内嵌页面打不开，可以点击页面上的“新窗口打开”。
3. 购买前核对商品说明、可兑换余额、付款币种、金额和交付方式。
4. 按商店的提示完成购买，保存订单号和兑换码。

站内余额和费用使用美元计价，页面显示 `$`。商店的实际付款金额、币种与兑换后余额不一定相同，**不能把人民币付款金额直接当成站内余额数值**。本教程不保证商店当前价格、库存或固定兑换比例。

兑换码是尚未使用的凭证，不要截图发给别人，也不要公开展示完整内容。

### 第二步：把兑换码换成余额

1. 回到本站，打开[兑换余额](/redeem)。
2. 完整粘贴余额兑换码，检查没有误复制空格或换行。
3. 提交并查看兑换结果，确认新增金额和当前余额。
4. 成功后可在兑换记录中核对；同一兑换码不能重复领取。

本节介绍余额兑换码。其他类型的码按页面显示领取对应资源，不一定增加余额。

### 兑换不成功怎么办

- **格式错误、无效或已使用**：核对完整兑换码、订单和兑换记录，不要连续反复尝试。
- **显示成功但余额没有变化**：刷新页面并核对兑换类型和记录；必要时重新登录。
- **仍有疑问**：私下联系管理员，提供订单号、购买时间和脱敏后的错误提示。不要发送密码、完整 API Key 或完整兑换码。
