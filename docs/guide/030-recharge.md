## 充值：先买兑换码，再兑换余额

本站充值分成两步：**先购买兑换码，再回本站兑换余额**。买完兑换码不等于已经充值，必须完成第二步。

### 第一步：购买兑换码

1. 登录本站，打开[购买兑换码](/redeem-store)。
2. 选择需要的金额。
3. 按购买页面的提示完成付款。
4. 付款后保存订单号和兑换码。

购买页面可能由其他商店提供，页面样式、价格和交付方式可能会变化。请以购买时看到的页面为准。

兑换码相当于未使用的充值凭证。不要截图发给别人，也不要在群聊里展示完整内容。

### 第二步：把兑换码换成余额

1. 回到本站，打开[兑换余额](/redeem)。
2. 完整粘贴兑换码。
3. 检查开头和结尾没有空格，然后提交。
4. 看到“兑换成功”后，回到控制台查看余额。

一张兑换码通常只能成功使用一次。已经显示成功后，不要再次提交。

### 兑换不成功怎么办

- **提示“格式错误”**：重新复制兑换码，并删除前后的空格或换行。
- **提示“无效”或“已使用”**：核对订单和兑换记录，不要连续反复尝试。
- **显示成功，但余额没有变化**：刷新页面；仍没有变化时，退出后重新登录。
- **还是不能解决**：私下联系管理员，提供订单号、购买时间和页面提示。截图前遮住密码、API Key 和完整兑换码。
