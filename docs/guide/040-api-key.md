## API Key：给软件使用的专用密码

Codex 不能直接使用你的登录密码，它需要 API Key 来连接本站。

### 创建 API Key

1. 打开[API Key 管理](/keys)。
2. 点击“创建 API Key”。
3. 填一个自己看得懂的名称，例如“我的电脑”或“Codex”。
4. 如果页面要求选择分组，可以先选择日常使用的分组；不确定时以页面说明为准。
5. 测试用的 Key 建议设置额度，避免意外产生太多费用。
6. 创建后妥善保存。页面如果只显示一次，请当场复制。

“分组”是页面提供的不同服务选项，可能影响可用模型和费用。不确定选哪个时，先看创建页面上的说明。

### 怎么保管

- 每台电脑或每个软件单独创建一个 API Key。以后出问题时，只需停用对应的那一个。
- 不要把 API Key 写进公开代码、帖子、截图或聊天记录。
- 不要把自己的 API Key 借给别人，也不要出售账户或 Key。
- 不再使用的 API Key 要删除或停用。
- 经常查看[用量记录](/usage)。看到陌生时间、模型或费用时，立即停用相关 Key。
